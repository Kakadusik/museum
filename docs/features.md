# Возможности интерфейса

Одностраничное приложение (SPA) на Nue 2.0. Роутинг на клиенте, данные — через API.

## Страницы

### Дашборд (`/`)

- Карточки счётчиков: предметы, исследователи, выставки
- Разбивки: по области науки, по статусу, по эпохе
- Ссылка на каталог предметов

### Предметы (`/items`)

- Список предметов карточками: название, статус, область науки, материал, исследователь, описание
- Фильтры: поиск по названию/описанию (`q`), область науки, статус, материал
- Фильтры сохраняются в URL (query-параметры) — страницей можно поделиться ссылкой
- Кнопка «Добавить предмет» — popover-диалог с формой (название, область науки, статус, описание, материал, эпоха, происхождение, научное объяснение, источник, исследователь, чекбоксы выставок)
- Состояния: загрузка, пусто, карточки

### Детали предмета (`/items/:id`)

- Полная информация: описание, область науки, материал, эпоха, происхождение,
  научное объяснение и ссылка на научную публикацию (DOI)
- Исследователь (ссылка на его страницу) и специализация
- Выставки, в которых экспонируется (ссылки)
- «Редактировать» — диалог с формой: все поля + выбор исследователя + чекбоксы выставок
- «Удалить» — диалог подтверждения

### Исследователи (`/explorers`)

- Таблица: имя, специализация, национальность, год рождения, количество найденных предметов
- Кнопки «Изменить» и «Удалить» в каждой строке (модальные диалоги)
- «Добавить исследователя» — popover-диалог (имя, специализация, год рождения, национальность, биография)

### Детали исследователя (`/explorers/:id`)

- Биография, год рождения, национальность
- Список найденных предметов (карточки со ссылками)

### Выставки (`/exhibitions`)

- Таблица: название, локация, описание, количество экспонатов
- CRUD через диалоги (как у исследователей)

### Детали выставки (`/exhibitions/:id`)

- Описание, локация
- Список экспонатов (карточки со ссылками)

### SQL-консоль (`/sql`)

- Текстовое поле для SQL-запроса (read-only: SELECT, WITH, EXPLAIN, SHOW)
- Кнопка «Выполнить» и готовые примеры запросов
- Таблица результатов: колонки и строки из ответа
- Счётчик строк и вывод ошибок SQL
- Запись/изменение/удаление данных через консоль запрещены

## Общие возможности

- **Клиентский роутинг** без перезагрузки страницы: `/`, `/items`, `/items/:id`, `/explorers`, `/explorers/:id`, `/exhibitions`, `/exhibitions/:id`, `/sql`
- **Навигация** через шапку и ссылки между сущностями (предмет → исследователь → выставка)
- **Autocomplete исследователя** в форме добавления предмета: ввод имени с фильтрацией и выбором из подсказок (вместо ручного ввода ID)
- **Клиентская валидация форм**: `required`, `minlength`/`maxlength` по размерам полей БД, числовые диапазоны года рождения
- **Диалоги** на нативном `<dialog>` (popover и модальные)
- **Адаптивная вёрстка** (CSS Grid, мобильная версия)
- **Статусы** предметов с цветовой индикацией: `on_exhibition` / `in_storage`;
  подписи («На выставке», «В хранилище») приходят из `/api/meta` и `status_label`
