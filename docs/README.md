# Музей Невозможных Предметов — документация

Архив-музей предметов, нарушающих законы физики, времени и логики.

## Стек

- **Бэкенд:** Python 3.10+, Sanic 23.12, Tortoise ORM 0.21, asyncpg, PostgreSQL
- **Фронтенд:** Nue 2.0 (Nuekit 2.0.0-beta.2), Bun 1.4
- **База:** PostgreSQL 16

## Текущий статус

Приложение полностью работает:

- Все 12 JS-модулей фронтенда компилируются без ошибок
- API покрыто e2e-тестами (44 проверки, все проходят)
- Демоданные: 7 предметов, 3 исследователя, 3 выставки
- Сервер раздаёт и API, и статику фронтенда на одном порту (8010)

## Быстрый старт

```powershell
# Сборка фронтенда (если менялись исходники)
cd frontend; nue build

# Запуск (БД PostgreSQL должна быть запущена)
cd ..; .\.venv\Scripts\python.exe backend\app.py
# → http://127.0.0.1:8010
```
